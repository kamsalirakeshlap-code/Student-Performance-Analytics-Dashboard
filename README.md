# Student Performance Analytics Dashboard

## Project Overview
This project analyzes student academic performance using Python and data visualization.

## Technologies Used
- Python
- Pandas
- Streamlit
- Plotly

## Features
- Student dataset display
- Department and gender filters
- Subject-wise marks visualization
- Subject average comparison
- Top performer identification
- Student performance ranking
- Download filtered student data as CSV

## How to Run
1. Install Python.
2. Install dependencies:
   pip install -r requirements.txt
3. Run the application:
   py -m streamlit run app.py

## Dataset
The dataset contains student details and marks in Python, Maths, DBMS, and Statistics.
